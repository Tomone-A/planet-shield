# Planet Shield

マウス操作で惑星を守る2D防衛ゲーム

![Python](https://img.shields.io/badge/Python-3.x-blue)
![Pyxel](https://img.shields.io/badge/Pyxel-1.x-green)

## 概要
世界を守るには少し小さい気もする防衛シールドは、あなたの手にたくされた。<br>
中心の惑星に向かってくる隕石から、回転するバリアを操作して惑星を守るアクションゲームです。<br>
大学1年次に、授業の最終課題として作成しました。<br>
三角関数を用いた円運動の実装と、動的難易度調整システムが特徴です。

## ゲーム画面

- 中心の緑の円：あなたの住む惑星
- 青い円：マウスで操作するバリア（防衛シールド）
- 小さな円：降ってくる隕石

## 操作方法

- **マウス移動**：バリアを操作
- **スペースキー**：緊急回避（全隕石消滅、スコア-1）
- **?ボタン**：ゲーム内ヘルプ表示

## ルール

- バリアで隕石を防ぐと+1点
- 惑星に隕石が当たるとダメージ
- 10回ダメージを受けるとゲームオーバー
- 10点ごとに隕石が1つ増加

## 技術的特徴

### 円運動の実装
`atan2`関数でマウス位置への角度を計算し、バリアが惑星の周囲を滑らかに追従します。

### 視覚的フィードバック
- ダメージに応じて惑星の色が変化（緑→黄→赤）
- 中心の穴が徐々に拡大してHPを表現

### 難易度調整
スコアに応じて敵の数が増加し、プレイヤーの成長に合わせた難易度を提供します。
